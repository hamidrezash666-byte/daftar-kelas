# دفتر کلاس — نسخه آماده GitHub Actions

اپلیکیشن Native Android با Kotlin، Jetpack Compose، Room و MVVM برای مدیریت کلاس.

## ساخت APK بدون Android Studio
این پروژه برای ساخت ابری با **GitHub Actions** آماده شده است.

- Workflow: `.github/workflows/build.yml`
- Java: JDK 17
- Gradle: 8.10.2
- خروجی: `app/build/outputs/apk/debug/app-debug.apk`

پس از قرار دادن پروژه در GitHub، از بخش **Actions** اجرای `Build Android APK` را اجرا کنید و APK را از **Artifacts** دریافت کنید.

## امکانات موجود
- رابط فارسی و RTL و طراحی موبایل‌محور
- کلاس مجازی: حضور/غیاب، تکلیف کامل/ناقص، آمار و گزارش PNG
- کلاس حضوری: حضور/غیاب و ارسال مستقیم SMS برای غایبان دارای شماره
- ارسال SMS به‌صورت صریح از SIM 2 در گوشی دو سیم‌کارته
- ثبت وضعیت ارسال SMS برای جلوگیری از ارسال تکراری همان رکورد
- مدیریت دانش‌آموزان
- تاریخ شمسی خودکار
- تنظیمات مدرسه، معلم، کلاس و متن پیامک
- Backup JSON

## نکته مهم
این Workflow ساخت APK را خودکار می‌کند، اما موفقیت ساخت و اجرای کامل برنامه باید در GitHub/روی یک گوشی واقعی Android نیز تست شود؛ مخصوصاً بخش SMS و انتخاب SIM 2 که به سخت‌افزار و نسخه Android گوشی وابسته است.
